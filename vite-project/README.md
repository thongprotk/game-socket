# React + Vite

Name: Game Socket - Bao Đấm Xì
Description: A simple game socket using React and Vite
Author: Bùi Trung Thông

This is project is a simple game socket application built using React and Vite. It demonstrates how to create a real-time multiplayer game using WebSockets. And the game is Bao Đấm Xì (Rock-Paper-Scissors). Game rules are simple: Rock beats Scissors, Scissors beats Paper, and Paper beats Rock.

#### Result:

- Learn how to set up a React project with Vite
- Understand the basics of WebSocket communication
- Create a simple multiplayer game
- Implement responsive design for better user experience
- Use modern JavaScript features and React hooks
- Structure a React application with components and state management
- Optimize the application for performance and scalability
- Test the application for bugs and usability issues
- Gain experience in front-end development with React and Vite
- Explore additional libraries and tools to enhance the application

## Features

- Real-time multiplayer game
- Responsive design
- Easy to set up and run
- Built with React and Vite for fast development
- WebSocket integration for real-time communication
- Simple and clean UI
- Modular component structure
- Hot module replacement for instant updates during development
- Optimized build for production

## Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/game-socket.git
   ```
2. Navigate to the project directory:
   ```bash
   cd game-socket/vite-project
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:5173` to see the application.
